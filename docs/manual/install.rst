============
Installation
============

Requirements
============

* Python 3.8+
* Django 3.2+ (Latest Django versions supported)

Install
=======

django-honeypot-admin is on `PyPI`_ and can be installed with `pip`_:

::

    pip install django-honeypot-admin

.. _PyPI: http://pypi.python.org/
.. _pip: http://www.pip-installer.org/

Note
====

This package is a fork of the original `django-admin-honeypot`_ by Derek Payton,
updated and maintained by Vignesh (Alien501) for compatibility with latest Django versions.

.. _django-admin-honeypot: https://github.com/dmpayton/django-admin-honeypot
